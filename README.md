# Calculator

My first self-written program — a command-line calculator with seven arithmetic operations, built for Programming Fundamentals at SSUET.

## Features

- **Seven operations:** add, subtract, multiply, divide, power, modulus, and floor division
- **One function per operation:** each takes two numbers and returns the result
- **Interactive input:** reads two numbers from the user and prints every operation's result
- **Labeled output:** each result is printed with a description so the output is readable

## How to Run

```bash
python calculator.py
```

## What I Learned

1. **Functions:** writing one function per operation, with parameters and return values
2. **Arithmetic operators:** `+ - * / ** % //` — including the difference between division, floor division, and modulus
3. **Input handling:** reading numbers from the user with `int(input(...))`
4. **Explaining my own code:** I only used concepts covered in class, so I can explain every line
